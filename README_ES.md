# Términos de uso de CeriumCore
## Type version 1.11
## Lang ES

## 1. Uso general
- 1. Se permite usar el núcleo para instalar paquetes de texturas y plugins con fines personales.
- 2. Está prohibido vender el núcleo en sí, así como los paquetes o plugins distribuidos con él, sin el permiso del autor.
- 3. Está prohibido presentar CeriumCore como un producto propio, incluso si has cambiado algunas líneas.
- 4. El autor no se responsabiliza de baneos, pérdida de datos ni fallos del juego.
- 5. Al publicar videos o posts en redes sociales (por ejemplo, YouTube, Telegram), se agradece mencionar al autor (MissGera), pero no es obligatorio.

## 2. Modificaciones y proyectos derivados
- 1. Se permite modificar el código para uso personal.
- 2. Al publicar un rebuild/mod/tu propio núcleo basado en CeriumCore, es obligatorio indicar al autor original (MissGera). Se agradece incluir el enlace a VForge.
- 3. Está prohibido vender proyectos derivados sin el permiso escrito del autor.
- 4. Está prohibido eliminar u ocultar la mención de autoría en el código o en el README.
- 5. Un proyecto derivado no debe llamarse "CeriumCore": usa tu propio nombre único.

## 3. Plugins y contenido de terceros
- 1. El autor del núcleo no se responsabiliza del código de plugins de terceros.
- 2. Los plugins se ejecutan bajo tu propio riesgo. Eres responsable de verificar lo que descargas.
- 3. Está prohibido distribuir plugins, texturas o cualquier otro contenido que viole las reglas de Blockman Go / VForge.

## 4. Disposiciones generales
- 1. Al usar CeriumCore, aceptas automáticamente estos términos.
- 2. El autor puede modificar estos términos. La versión actual siempre se incluye en la última versión de CeriumCore y se publica en las redes sociales del autor.
- 3. Estos términos se aplican a todas las versiones de CeriumCore.
