# Changelog · История версий

## v1.13 "Star" — Pre-release
**Build 11300**

- **Вкладка RUNCODE:** Полноценный Lua-редактор, кнопка выполнения кода, окно вывода, история последних 5 запусков.
- **Plugin Creator:** Форма создания плагина (Имя, Автор, Версия, Описание) из кода в RunCode. Автоматическая сборка `script.lua` и `manifest.json`.
- **Plugin Manager:** Экран управления плагином (EDIT, DUPLICATE, DELETE). Редактирование метаданных и кода без выхода из игры.
- **Автобэкапы:** При редактировании или удалении плагина автоматически создается резервная копия в `cerium-scripts/_cerium_backups/`.
- **Просмотр логов игры:** Вкладка LOG полноценного работает, теперь имеет переключатель между логом ядра (`cerium.log`) и логом клиента BG (`server.log`).
- Добавлены недостающие кнопки EDIT в список плагинов.
- Улучшено отображение иконок паков

### 🐞 Исправления
- **[FIX] Превью текстур-паков:** Отображение превью теперь полностью рабочее, для добавления иконки добавь ключ `"preview"`, и добавь иконку в папку с текстурой:
```json
{
  "name": "Name",
  "version": "1.13",
  "description": "Desc",
  "author": "MissGera",
  "engine": 1,
  "preview": "icon.png" <-- укажи название .png
}
```
- **[FIX] U.mkdir:** Сделана рекурсивной для создания вложенных папок.
- **[FIX] Тексты:** Убраны вызовы несуществующего `setTouchThrough`, которые вызывали ошибки привязки CEGUI.
- **[FIX] U.grad:** Переписан на нативный формат градиента `&$[RRGGBBAA-RRGGBBAA]$ТЕКСТ$&` для правильного отображения.

### ⚙️ Технические изменения
- Смена базового пути на `g20368480` (полный переход на новый режим).
- Добавлен `P.BMGO_LOG` для доступа к `server.log`.
- Переписана логика `C.pngValid` и `X.previewImage`.
- `S.runCode` вынесен в отдельное состояние (независимо от плагинов).
- Обновлен `S.STR` (добавлены ключи для RUNCODE, Plugin Creator и логов).
