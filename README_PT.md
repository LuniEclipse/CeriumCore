# Termos de uso do CeriumCore
## Type version 1.11
## Lang PT-BR

## 1. Uso geral
- 1. É permitido usar o núcleo para instalar pacotes de texturas e plugins para fins pessoais.
- 2. É proibido vender o próprio núcleo, bem como os pacotes ou plugins distribuídos com ele, sem a permissão do autor.
- 3. É proibido apresentar o CeriumCore como seu próprio produto, mesmo que você tenha alterado algumas linhas.
- 4. O autor não se responsabiliza por banimentos, perda de dados ou falhas no jogo.
- 5. Ao publicar vídeos ou posts em redes sociais (por exemplo, YouTube, Telegram), mencionar o autor (MissGera) é apreciado, mas não obrigatório.

## 2. Modificações e projetos derivados
- 1. É permitido modificar o código para uso pessoal.
- 2. Ao publicar um rebuild/mod/seu próprio núcleo baseado no CeriumCore, é obrigatório indicar o autor original (MissGera). Incluir o link para o VForge é apreciado.
- 3. É proibido vender projetos derivados sem a permissão por escrito do autor.
- 4. É proibido remover ou ocultar a menção de autoria no código ou no README.
- 5. Um projeto derivado não deve se chamar "CeriumCore" — use seu próprio nome único.

## 3. Plugins e conteúdo de terceiros
- 1. O autor do núcleo não se responsabiliza pelo código de plugins de terceiros.
- 2. Os plugins são executados por sua conta e risco. Você é responsável por verificar o que baixa.
- 3. É proibido distribuir plugins, texturas ou qualquer outro conteúdo que viole as regras do Blockman Go / VForge.

## 4. Disposições gerais
- 1. Ao usar o CeriumCore, você concorda automaticamente com estes termos.
- 2. O autor pode alterar estes termos. A versão atual está sempre incluída na versão mais recente do CeriumCore e é publicada nas redes sociais do autor.
- 3. Estes termos se aplicam a todas as versões do CeriumCore.
