# A detailed, complete guide to installing the CeriumCore.
## Android:
- Search for BG: **5v5 Brawl**
- Enter **5v5 Brawl**
- Wait a few seconds and exit the game
- Download your chosen version of CeriumCore; I recommend downloading the latest versions.
- Replace the downloaded archive **g20368480.zip** with:
```
/storage/emulated/0/Android/data/com.sandboxol.blockymods/files/Download/SandboxOL/BlockManv2/map_temp/g20368480/
```
- Make sure the replaced file is named g20368480.zip. If it's named something else, nothing will work.
- Enter **5v5 Brawl** again.
- Done!
## Emulator:
- Follow the same steps as above, but in your own environment.
