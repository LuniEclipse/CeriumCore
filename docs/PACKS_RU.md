# 🎨 Создание текстур-паков под CeriumCore

Текстур-паки в CeriumCore — это обычные ZIP-архивы с текстурами, упакованные по правилам игры, плюс файл `manifest.json` для отображения информации в меню.

## 📁 Структура пака
Папка пака кладется в `cerium-texture/`:
```
cerium-texture/
└── my_cool_pack/
    ├── texturepack.zip  (архив с папками текстур: textures/, assets/ и т.д.)
    ├── manifest.json    (информация о паке)
    └── preview.png      (опционально: картинка 256x256 для меню)
```

## 📝 manifest.json
Создайте этот файл в папке с паком. Все поля опциональны, но рекомендуются:
```json
{
  "name": "Мой крутой пак",
  "version": "1.0",
  "author": "YourName",
  "description": "Заменяет все алмазы на котов.",
  "engine": 1,
  "preview": "preview.png"
}
```

- **name**: Название пака.
- **version**: Версия.
- **author**: Автор.
- **description**: Описание (до 200 символов, выводится в меню).
- **engine**: `1` (1 движок) или `2` (2 движок). Влияет на то, куда ядро запишет архив.
- **preview**: Имя файла превью (лежит в той же папке, что и манифест).

## 📦 Как собрать texturepack.zip?
1. Создайте папку Media
2. Вставляйте нужные текстуры/файлы туда, в некоторых случаях рекомендуется в папках которые игра принимает, например: Media/LightingV2/, Media/Scripts/Engine/
3. Текстуры/файлы должны быть обязательно называться так, как называются в оригинале, например: stone.png, sand.png, res.pack, gameloading.json (в некоторых местах названия можно редактировать самостоятельно на свои, но нужно править нужные .json)
3. Заархивируйте Media в **строго в ZIP** (не RAR, не 7z). Внутри архива папки должны лежать в корне Media.
4. Назовите архив `texturepack.zip` и положите в папку пака.

## ⚠️ Важно
- Если `texturepack.zip` битый или не ZIP, ядро покажет статус **BAD ZIP** и не даст применить пак.
- В версии 1.12+ можно держать разные паки на движке 1 и движке 2 одновременно.
